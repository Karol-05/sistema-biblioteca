# Sistema de Biblioteca

Projeto acadêmico desenvolvido com Java (Programação Orientada a Objetos) e PostgreSQL.

## Exercícios

1. Sistema de biblioteca em Java com classes, herança e polimorfismo.
2. Modelagem relacional e criação das tabelas no PostgreSQL.
3. Quatro consultas SQL sobre os dados cadastrados.

## Estrutura

- java/src/: implementação Java.
- sql/modelagem.sql: criação das tabelas e dados de teste.
- sql/consultas.sql: consultas SQL.

- exercicio-2-modelagem-sql
